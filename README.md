# Estrelas do Amanhã — Matrícula

Interface de formulário de matrícula escolar, com dados da criança, endereço, responsável e opções de matrícula.

## Tecnologias

HTML e CSS.

## Como visualizar

```sh
git clone https://github.com/mateushdsouza/projeto-formulario-de-matricula.git
cd projeto-formulario-de-matricula
```

Abra [index.html](index.html) no navegador. Não é necessário instalar dependências. Fontes externas, quando utilizadas, precisam de internet.

## Organização

- [index.html](index.html): estrutura da página.
- [styles/](styles/): estilos.
- [assets/](assets/): imagens e ícones.

## Estado atual e limitações

Não há backend ou armazenamento de matrículas. O formulário é demonstrativo; o envio POST não tem um serviço configurado.

## Aprendizado

Estruturação de conteúdo em HTML, organização de estilos e composição visual. A presença de uma interface não representa um serviço completo em produção.
